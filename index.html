Saving and sharing — keep everything in a Firebase database

Without this, everything is saved in this browser only. Point it at a Firebase Realtime Database and the cabin list, rules and crew follow you to any computer on board.

The token is kept in this browser and sent as a query parameter, so use a database whose rules limit this path to your crew.
